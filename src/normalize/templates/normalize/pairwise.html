Pairwise sensitivity

How robust is each ordering? Model-based probability that one top contender outranks another. Organizer view.

This panel is a live recompute over the current ballots — not part of any signed or published result. Each probability is the fraction of the same parametric bootstrap draws the leaderboard's rank intervals use in which the row project's severity-adjusted quality q exceeds the column project's. It measures only how stable an ordering is under sampling noise — not merit, and not fraud detection.
